# Jimaku · 字幕

**Omarchy**上でアプリの再生音声をリアルタイムに翻訳し、字幕として表示します。アプリで音声を再生して**「翻訳を開始」**を押すと、移動・サイズ変更できる別ウィンドウに翻訳が表示されます。ブラウザやメディアプレーヤーなど、PipeWire-Pulse経由で取得できる再生ストリームが対象です。

[English](README.md) · [テスト](TESTING.md) · [公開チェックリスト](docs/PUBLISHING.md) · [MITライセンス](LICENSE)

## 作った理由

英語の動画を日本語字幕で見たかったのですが、私の環境ではChromeの字幕・翻訳機能が安定して動きませんでした。Xの動画にも字幕機能はあるものの、私が使っていた視聴環境では、その字幕を翻訳できませんでした。

私はXを **[Biscuit](https://eatbiscuit.com/ja/)というElectronベースのアプリブラウザ**で見ています。そのためChrome内だけで動く機能ではなく、ブラウザや動画側の字幕機能に依存せず、どのアプリの再生音声でも翻訳できるようにしたいと考えました。

Jimakuは選択したアプリの再生ストリームから翻訳し、別ウィンドウに表示します。元動画の字幕や、ページを読み取るブラウザ拡張機能は不要です。Omarchy上でPipeWire-Pulse経由で取得できる再生ストリームが対象です。ブラウザが複数タブの音声を一つにまとめる場合もあります。

## 機能

- 再生中のストリームを自動検出し、音声ソースを自動選択。
- 翻訳だけを表示する字幕。句読点を優先した分割と、文字サイズの自動調整。
- リアルタイム優先（初期値）と読みやすさ優先。どちらも字幕が溜まると表示時間を短縮。
- カーソル操作で現れるツールバー。装飾メニューを開いていても、操作が止まると非表示。
- OSの言語を初期値とする13言語の翻訳先。日本語／英語UIとOmarchyのテーマ色に対応。
- 翻訳履歴をローカル保存し、設定から既定のテキスト用アプリで開く機能。

## 「Jimaku」の意味

**Jimaku（字幕・じまく）** は、日本語の「字幕」をローマ字にした名前です。Jimakuはコミュニティ製で、Omarchy・OpenAIの公式製品ではありません。

## 必要な環境

- **Omarchy Shellのプラグイン機構**が使えるOmarchy（`omarchy plugin`、`omarchy-shell`、Quickshell）。旧Waybarのみの構成は対象外です。
- PipeWire-Pulse、`pactl` / `parec`、Python 3.11以上、`uv`。
- 課金設定と `gpt-realtime-translate` の利用権限があるOpenAI APIキー。API利用料は別途かかります。[最新料金](https://developers.openai.com/api/docs/models/gpt-realtime-translate)を確認してください。

## インストール

公開リポジトリから導入し、Python実行環境をセットアップします。

```bash
omarchy plugin add https://github.com/agata/omarchy-jimaku.git --enable
bash "${XDG_CONFIG_HOME:-$HOME/.config}/omarchy/plugins/io.github.agata.jimaku/setup.sh"
```

または、リポジトリを削除・移動しない場所へダウンロードまたはcloneし、コードを確認して実行します。

```bash
bash install.sh
```

プラグインを検証し、バージョン固定のPython依存関係を `${XDG_DATA_HOME:-$HOME/.local/share}/jimaku/runtime` に入れ、このチェックアウトへのリンクをOmarchyのユーザープラグイン領域に作成して有効化します。実行中のOmarchy Shellセッションが必要です。sudoやデスクトップ設定の自動書き換えは行いません。リンク元のフォルダは移動しないでください。

`omarchy plugin add` やプラグインメニューから導入した場合、Omarchyは**セットアップスクリプトを実行しません**。導入後と更新後に実行してください。

```bash
bash "${XDG_CONFIG_HOME:-$HOME/.config}/omarchy/plugins/io.github.agata.jimaku/setup.sh"
```

その後、Jimakuを閉じて開き直します。依存関係が不足していれば、翻訳を始めずセットアップ案内を表示します。依存関係のダウンロードは明示的にセットアップを実行したときだけ行い、プラグインを開くだけでは行いません。

### フローティング表示

Lua版Hyprlandを使うOmarchyでは、`~/.config/hypr/hyprland.lua` に次を追加し、`hyprctl reload` を実行します。

```lua
-- Jimaku floating captions
o.window({ title = "^Jimaku — Live captions$" }, { float = true })
```

移動・サイズ変更は通常のウィンドウ操作で行えます。プラグインIDは `io.github.agata.jimaku`、設定と履歴の保存先は `jimaku` ディレクトリです。

## 使い方

1. バーの字幕アイコンを開き、「設定」でAPIキーを保存します。
2. 別のアプリで音声を再生します。再生ストリームは自動更新され、複数ある場合は対象を選びます。
3. **「翻訳を開始」**で選択したストリームの送信を開始し、字幕モードに入ります。
4. 字幕上でカーソルを動かすと操作ボタンが現れます。文字サイズや見た目を調整でき、**⋯**から表示速度・設定・操作画面へアクセスできます。
5. **「停止」・Ctrl+Space・ウィンドウを閉じる操作**で翻訳を止めます。**Esc・ダブルクリック・右クリック**は、**翻訳を継続したまま**操作画面へ戻ります。

設定には、録音・API通信・履歴保存を行わないデモがあります。固定の日本語サンプルで、実際の翻訳ではありません。

**翻訳先：** 初期値はOSの言語です。未対応の場合は英語になります。英語・日本語・中国語・韓国語・スペイン語・ポルトガル語・フランス語・ドイツ語・イタリア語・ロシア語・ヒンディー語・インドネシア語・ベトナム語に対応します。翻訳停止中に変更してください。UI言語は独立しており、OSが日本語なら日本語、それ以外は英語です。

**表示速度：** リアルタイム優先は最低0.8秒表示し、句読点を最大1.8秒待ちます。待ち字幕が溜まると古いものを飛ばします。読みやすさ優先は通常2.2〜6秒で、待ち字幕が増えると最低1秒まで短縮します。どちらもキューに上限があり、すべての字幕が画面に出るとは限りません。受信した翻訳全文は履歴に保存されます。APIの待ち時間はなくせず、動画を遅延させて字幕と同期する機能はありません。

## プライバシーと保存データ

音声をOpenAIへ送信するのは**「翻訳を開始」を押した後だけ**です。自動検出では再生ストリームを一覧取得するだけです。選択したストリームを取得し、マイクやPC全体の音声へ自動切り替えはしません。ブラウザが複数タブを一つのストリームにまとめる場合があるため、他のタブの音声は止めてください。

| 保存データ | 標準の保存先 | 保存形式 |
| --- | --- | --- |
| APIキー | `~/.config/jimaku/openai-key` | 平文、所有者のみ読み書き可能（0600） |
| 設定 | `~/.config/jimaku/settings.json` | ローカルのJSON |
| 翻訳文 | `~/.local/share/jimaku/translations.txt` | 追記形式の平文、0600。日時と翻訳先を記録 |
| Python実行環境 | `~/.local/share/jimaku/runtime/` | `setup.sh` で再作成可能 |

`XDG_CONFIG_HOME`・`XDG_DATA_HOME` に応じて保存先が変わります。デスクトップセッションに `OPENAI_API_KEY` が設定されていれば、保存したキーより優先します。キーと履歴は**暗号化していません**。音声・原文は保存せず、アクセス解析も行いません。履歴は自動ローテーションしないため、翻訳停止中に整理・削除してください。送信した音声のOpenAI側での取り扱いは、APIアカウントの設定と提供元のポリシーに従います。

再生ストリームの消失・出力先変更で録音を停止します。約10秒のほぼ無音・一時停止・ミュート、または1時間経過でも停止します。通信エラー後は手動で再開し、自動再接続はしません。翻訳精度や遅延は状況によって変わります。

## 更新と削除

git管理されたマーケットプレイス経由の導入では、次を実行します。

```bash
omarchy plugin update io.github.agata.jimaku
bash "${XDG_CONFIG_HOME:-$HOME/.config}/omarchy/plugins/io.github.agata.jimaku/setup.sh"
```

リンクで導入した場合はリンク元を更新し、`bash setup.sh` を再実行します。その後Jimakuを閉じて開き直してください。QMLの変更がキャッシュに残る場合は、翻訳を停止してから `omarchy restart shell` を実行します（デスクトップのシェル全体が再起動します）。

削除前にも翻訳を停止してください。

```bash
omarchy plugin remove io.github.agata.jimaku
```

Omarchyはプラグイン登録とチェックアウト、またはリンクを削除します。キー・設定・実行環境・履歴は残ります。完全に削除する場合は必要な履歴を退避し、XDGのconfig/data領域の `jimaku` ディレクトリと、追加したウィンドウルールを削除してください。リンク元のソースフォルダは別途削除できます。

## トラブルシューティング

- **セットアップが必要：** `setup.sh` を実行してください。必要なコマンドを確認して依存関係を導入します。システムのPython更新後にも再実行してください。
- **音声が検出されない：** 再生を開始し、一時停止・ミュートされていないか確認してください。検出はストリームの状態を使い、音声認識ではないため、無音でも再生中のストリームは候補に出る場合があります。
- **接続できない：** APIの課金設定・モデル利用権限・通信・キーを確認してください。提供元からの機密情報を含み得る応答はログへ書きません。
- **字幕が遅い：** リアルタイム優先を使ってください。APIの遅延やアプリ側の音声バッファリングは残ります。
- **フローティング設定が効かない：** 上の例はLua版Hyprland向けです。導入しているHyprlandのバージョンに対応した書式を使ってください。

## 開発

```bash
bash setup.sh
bash scripts/test.sh
```

テストはサンプル文章と模擬APIセッションを使い、有料の翻訳APIを呼び出しません。追加のQtテストと検証範囲は [TESTING.md](TESTING.md) を参照してください。変更時は必要な回帰テストを追加し、安全な停止・APIキーの扱い・既存設定との互換性を維持してください。
